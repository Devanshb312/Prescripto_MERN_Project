# Prescripto - MERN Stack Doctor Appointment Booking System

Prescripto is a full-stack appointment booking system designed for hospitals and doctors. It supports **three levels of authentication** for Patients, Doctors, and Admins. The system is built using the **MERN stack (MongoDB, Express.js, React, Node.js)** and includes **online payment gateway integration** for seamless fee transactions.


---

## 👥 User Roles

### 🧑 Patient
- Register and log in
- Book appointments with available doctors
- Manage booked appointments
- Pay consultation fees online

### 🩺 Doctor
- Login and manage profile
- View upcoming appointments
- Track total earnings

### 🛠️ Admin
- Access Admin Dashboard
- Manage doctors' profiles
- Monitor and manage all appointments

---

## 🛠️ Tech Stack

**Frontend:**
- React.js (Vite)
- TailwindCSS 
- Axios
- React Router

**Backend:**
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT for Authentication
- Bcrypt.js for Password Hashing

**Payments:**
- Razorpay

---

## ⚙️ Features

- Secure JWT-based authentication
- Role-based access control (Patient, Doctor, Admin)
- Doctor profile management
- Real-time appointment dashboard
- Online payment support
- Responsive and modern UI
- RESTful API backend
